# Contractor Scheduler

Web application for managing contractors and scheduling their tasks.

## MVP

The initial version will allow an administrator to:

- Create and manage contractors.
- Create tasks for contractors.
- Schedule tasks using start and end times.
- Prevent overlapping tasks for the same contractor.
- View scheduled tasks in a calendar.

## Planned stack

- Python
- Django
- PostgreSQL
- Django Templates
- Bootstrap
- FullCalendar
